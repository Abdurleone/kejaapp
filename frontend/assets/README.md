Logo assets for the frontend live here.

`keja-logo.png` is the real KejaApp logo, resized to a 128x128 working copy (the original upload was a 2.2MB 1024x1024 PNG, too heavy to ship — it was shrunk to 512x512 first, then further down to the current 128x128 in a later pass). It's imported directly in `frontend/src/App.jsx` for the header brand mark, and a separate 64x64 copy lives at `frontend/public/favicon.png` for the browser favicon (referenced from `frontend/index.html`; `frontend/public/` is Vite's static-file directory, served as-is). The landing page hero itself uses a CSS gradient built from the app's theme colors, defined in `frontend/styles.css`, not a logo image.
