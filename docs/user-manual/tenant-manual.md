Quick Tasks

1) Create an account
- Open the app -> Sign up -> enter name, email, password
- Confirm email (if required)

2) Save a property
- Browse Discover -> open a listing -> click Save/❤

3) Request a viewing
- Open listing -> Request viewing -> select date/time -> submit

Troubleshooting
- I can't log in: check network, ensure account exists or use "Forgot password".
- I don't see saved properties: ensure you're signed in to the same account.
